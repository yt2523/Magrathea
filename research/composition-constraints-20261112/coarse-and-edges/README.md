# 96点粗网格与27点范围检查（固定测试热边界）

每点先输入M和Fe/Si/H2O/HHe分数，计算m_i=f_iM，再由真实C++模型计算R。比较观测R仅发生在输出后。三质量为7.56/8.04/8.54 M⊕，半径比较框2.28..2.49 R⊕；未知联合协方差，不能称后验或联合68%区域。

96粗点全部通过独立只读核验：89345保存状态，最大密度重算误差1.36e-7，严格表拒绝0，36无水点的水EOS调用0；72零硅点的硅EOS调用0。27范围点也均通过执行器检查，完整独立核验另行追加。两ZIP保存输入、原生模型、独立密度检查、runtime和日志原字节，配套raw-sha256按解压后逐文件核验；不是重新生成/缩放的模型。源码与二进制身份沿用已验B17和扫描器28。

初始气体上限1%时，无水与富铁端仍低于观测；补到10%后残差已异号，不可用原范围排除无水。极低气体的富水点反而增大R：官方AQUA四个包围格点相态列确认6个外水边界为vapor，72个为liquid或supercritical/superionic。气体质量同时改变水层起点P、熵与温度积分路径，不能按气体越少R越小假设单调，更不能平滑跨这些边界。诊断指外水边界，不代表整个水层物态已认证。
